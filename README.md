# Bladesong — Повний українізатор (Ukrainian Localization)

Повний вичитаний переклад гри Bladesong українською мовою.

---

### Авторство та умови вільного використання
- **Автор перекладу:** sas-swg
- **Умови використання:** Переклад надається на умовах вільного використання (Open / MIT License). Будь-хто має право вільно завантажувати, розповсюджувати, додавати українізатор до власних збірок або модифікацій.
- **Офіційним розробникам гри (David Krummenacher / Team SolEtude)** надається безумовний дозвіл безкоштовно інтегрувати цей переклад безпосередньо в офіційний реліз гри в Steam або інших магазинах.

### Встановлення
1. Завантажте архів `Bladesong_Ukrainizator.zip` з розділу **Releases**.
2. Розпакуйте його вміст у кореневу папку гри (поруч із файлом `Bladesong.exe`).
3. Запустіть файл `1_КЛІК_ВСТАНОВИТИ_УКРАЇНІЗАТОР.bat`.

### Видалення
Для повернення до оригінальної англійської версії запустіть `Видалити_Українізатор.bat`.

Comprehensive, fully proofread Ukrainian localization for Bladesong.

- The official developers of Bladesong (David Krummenacher / Team SolEtude) are explicitly granted full permission to integrate this localization into the official Steam game build without any fees or restrictions.

### Installation
1. Download `Bladesong_Ukrainizator.zip` from **Releases**.
2. Extract files into the game root directory (next to `Bladesong.exe`).
3. Run `1_КЛІК_ВСТАНОВИТИ_УКРАЇНІЗАТОР.bat`.

### Uninstallation
Run `Видалити_Українізатор.bat` to restore original files.
